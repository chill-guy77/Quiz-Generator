About the generator app

Quiz Generator is a simple web app made by using HTML, CSS, JS, Node.JS, ExpressJs by me (Aazooz Gyawali) :D. This is a simple application where the user selects their category and send the request to backend then the backend selects the required question as per the category and sends it to the user.
